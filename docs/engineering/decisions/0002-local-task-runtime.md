# ADR-0002：本机任务宿主与渐进切换

- 状态：试点已实现，生产页面验收未完成
- 日期：2026-10-04
- 授权：实施 M0–M3，M4–M6 仅规划

## 决策

使用标准库 SQLite 保存计划、授权、任务、条目、事件和命令。原拟采用的命名管道改为 SQLite 本机命令队列，减少协议与安装依赖；任务与派发命令在同一事务中创建。数据库只能放本机，不能在网络盘由多人直接写。

默认目录为当前用户的 %LOCALAPPDATA%\ConfigAssistant，可通过 CONFIG_ASSISTANT_HOME 或 task_data_dir 配置。目录继承 OS 权限，不是防御同一用户下恶意程序的沙箱。M4 仍须实现 AI 入口与可信人机授权边界；操作数据库不是 MCP 公共接口。

宿主以独立后台进程按需启动，空闲约 15 秒退出。OS 文件锁控制单实例；浏览器锁规范化 CDP 主机/端口，同一用户不同安装和数据目录仍共用锁。Playwright 由宿主线程创建、使用、销毁，入口只传普通数据。

自动任务不依赖 GUI 存活，逐条确认最多等候 30 分钟后停止后续操作。电脑关机、休眠或失去内网仍不能执行。重启时将运行中的试点任务标记中断，保留提交意图；只读核验不再次提交。

## 计划、身份与切换条件

计划不可替换，确认绑定摘要、选中条目、入口和模式。重复提交同一计划与选集返回原任务。执行前检查环境、会话、对象和前置状态；相同对象存在历史未知提交时阻止创建新执行。

首版会话指纹来自登录 cookie 的摘要，不保存 cookie，明确标记“浏览器会话，非实名核验”。不能替代平台账号查询；cookie 轮换可能要求重新预检，也不提供跨设备全局互斥。

旧[页面记录](../../价格策略批量开关-配置项抓取.md)指出价格配置表 row-key 重载后未必稳定。新适配器严格核对策略与行标识，不匹配就停止，绝不回退到第一条同名行。在稳定业务 ID 与真实页面验收完成前，通过 pricing_task_host、CLI 的 --task-core 或 GUI 试点勾选启用；默认保留旧价格执行器。

因此不能宣称 M2 生产验收完成，也不能宣称 14 项能力全部迁移。旧执行器仍在 GUI/CLI 进程中运行；互斥、断点修复和档案快照先覆盖它们。M5 逐项验证后才删除旧实现。

## 数据、兼容、验证

任务库版本为 1，拒绝更高版本；未知非空旧库先备份再拒绝覆盖。未来升版必须增加迁移与失败恢复测试。在线一致性备份使用 SQLite backup API，不能只复制 WAL 模式的主文件。

旧配置、台账、输入与 updater payload 边界保持原位，新任务目录不随代码更新覆盖。新增标准库模块也可能影响冻结运行时；M6 完成安装与升级实测前，不发布代码包或安装包。

离线测试覆盖计划、重复提交、持久化失败、未知结果、只读核验和反向计划；独立假平台进程测试验证多宿主、客户端离开和崩溃恢复。关闭试点可回到旧入口，但不能删除任务库规避未知提交。
