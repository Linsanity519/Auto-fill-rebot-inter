## 界面方案

`界面方案/` 下是三套 GUI 方案的视觉稿和方向 C 的技术选型，不是页面抓取记录。

## 怎么抓

程序自带的调试浏览器就够用，不用另外开工具：

```python
from src import chrome
from src.paths import app_dir
chrome.launch("http://127.0.0.1:9222", app_dir() / ".chrome-profile", "要抓的页面URL")
# 人工在弹出的窗口里登录（扫码），然后：
from src.browser import Browser
with Browser("http://127.0.0.1:9222", 30000) as b:
    p = b.page      # 标准 Playwright Page，随便点随便读
```

抓的时候注意记这几样，这几样最容易想当然：

1. **label 原文**（页面上写的是「我想投放」不是「人群标签」）
2. **同名 label 出现几次**、哪一个是要填的那个（人群那一段一个 label 出现 5 次）
3. **选项全集**（虚拟列表要滚到底，或者用搜索逐个确认）
4. **选了某个值之后才冒出来的字段**（在期大会员 → 必填的天数区间）
5. **控件真实类型**（多选下拉 ≠ 勾选框组，填法完全不同）
