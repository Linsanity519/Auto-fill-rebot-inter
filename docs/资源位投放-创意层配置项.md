# 资源位投放 — 创意层（第三步）配置项

抓取方式：在测试活动「子凡测试25年」(activityId=708) 下，为每个资源位新建单元并保存进入创意页，逐个展开选项抓联动字段。**未做任何提交审核操作。**

## 重要发现

### 1. 创意层是两套系统

| 系统 | URL | 举例资源位 |
|---|---|---|
| 新版 | `rich-vip.bilibili.co/delivery/creativity?unitId=&position=` | 会员中心领福利资源位 |
| 老版 | `manager.bilibili.co/v3/#/vip/resource-delivery/originality/detail?unitId=&position=` | 播放页催费条、开通提示条 |

保存单元后会自动重定向到对应系统。

### 2. `position` URL 参数只是显示用

创意表单实际按 **单元绑定的资源位** 渲染，改 URL 的 `position` 不会切换表单 —— 所以每个资源位必须真的建一个单元。

### 3. 单元层「投放展示位置」在编辑态锁死

只有 `state=create` / `state=copy` 能选资源位。

### 4. 建单元的可靠路径：`state=copy`

`/delivery/unit/0?state=copy&copyId=<已有单元id>&position=<n>&activityId=708&activityName=...&activityState=1&activityType=5`

复制态会把投放时间等预填好。（直接 `state=create` 时 antd RangePicker 无法通过脚本填写。）

保存前需补的必填项（切换资源位后会被重置，**需要补两遍**）：
- 生效平台：至少勾 1 个
- 内容类型 / ep付费状态：若该资源位有，至少勾 1 个
- 内容黑名单等 radio 组：若无默认选中，选第一个
- 版本限制等 select：若显示"请选择"，选第一项
