抓取时间：2026-08-18　页面：`rich-vip.bilibili.co/delivery/unit/0?state=create&activityId=708`
抓取方式：调试端口 9222 + Playwright 实地点开每一支，不是看截图猜的。

> 之前按运营给的「常用人群表」猜过一版（人群标签 / 6 个选项 / 勾选框组），**全错**。
> 这份是页面上真实的样子，改配置以这份为准。

## 一、整体层级

```
定向投放
├─ 人群选组            radio：不限 / 指定人群
│   └─（指定人群）
│       ├─ 人群选组     select（二级，同名 label！）5 个选项，见下表
│       └─ 按二级的值展开第三级，见下表
│       └─ 「添加人群配置」按钮 —— 可以加多组人群（我们只填第一组）
└─ 排除人群选组        radio：不限 / 指定人群
    └─（指定人群）
        ├─ 人群选组     select（二级，还是同名 label）只有 3 个选项
        └─ 在上述投放中我想排除   多选（27 项，同投放侧）
        └─ 「添加排除人群配置」按钮
```

## 二、二级「人群选组」→ 三级控件

| 二级取值 | 三级 label | 控件 | 备注 |
|---|---|---|---|
| 基本人群（实时数据） | **我想投放** | antd 多选 select，可搜索 | 27 个选项，见下节 |
| OGV DMP 人群包 | 人群名称 | 单选 select，远程搜索 | placeholder `请输入人群ID` |
| 指定人群包（离线数据） | 人群分组ID | 多选 select | placeholder `请选择` |
| 特殊人群包（当前人群特征无法满足的人群包） | 人群包key | 文本框 | placeholder `可用,（逗号）隔开输入进行多选` |
| 外部人群 | 人群来源 | 单选 select | 选项：移动-全球通-SDK / 江苏电信 |

排除侧的二级只有 3 个：基本人群（实时数据）/ 特殊人群包（…）/ OGV DMP 人群包。

## 三、「我想投放」/「在上述投放中我想排除」的 27 个选项

两边完全一样：

```
未登录　三新用户（mid&buvid&手机号）　大会员新用户（从未开通）　大会员支付新用户（从未支付）
ogv新用户　在期大会员　过期大会员　年度大会员
在期&即期1-3天大会员　在期&即期1-7天大会员　在期&即期1-30天大会员
过期1-3天大会员　过期1-7天大会员　过期1-30天大会员
敏感人群　未登录+大会员新用户(从未开通)　在期&即期大于30天大会员
在期超级大会员　过期超级大会员　签约大会员　签约超级大会员
年度大会员&最近开通时间>=93天　LV1　LV2　LV3　LV4　LV5
```

⚠ 运营那张表里的「在期 = 在期&即期大于30天大会员」这类说法只是口径，页面上
「在期大会员」和「在期&即期大于30天大会员」是**两个不同的选项**，别混用。

## 四、第四级：部分标签带「天数区间」参数

选中某些标签后，下面会多出一行**必填**参数：

| 选中的标签 | 多出来的行 | 控件 |
|---|---|---|
| 在期大会员 | `* 在期大会员即期 [n] 天至 [m] 天(从小到大)` | 两个 ant-input-number |
| 过期大会员 | `* 过期大会员过期 [n] 天至 [m] 天(从小到大)` | 两个 ant-input-number |
| 未登录 / 在期&即期1-30天大会员 / LV3 …… | 无 | — |

即：**带具体天数口径的标签（在期&即期1-30天大会员）自己就带了区间，不再要参数；
笼统的标签（在期大会员 / 过期大会员）才要你填区间。**

## 五、定位要点（写 yaml 时踩过的坑）

1. **二级和一级 label 同名**，都叫「人群选组」。页面上 `.ant-formily-item` 里
   label=人群选组 的项，投放侧展开后是 3 个：
   `[0]` 一级 radio、`[1]` 外层容器（里面有二级 select + 三级多选）、`[2]` 二级 select 本身。
   排除侧展开后再追加 `[3]` `[4]`。

2. 所以**不能写死 label_index**：人群选组=不限时排除侧的下标会前移。
   用 `label_index: -1`（取最后一个）——filler 是按 yaml 顺序填的，
   填投放侧二级时排除侧还没展开，填排除侧二级时它才是最后一个，两种情况都对。

3. 「我想投放」的 label 也命中 2 个表单项（外层容器 + 它自己），取 `label_index: 1`。
   容器里那个非多选的 select 是二级，多选的才是它。

4. 二级 select 在容器里排第一个、三级排第二个：`.ant-select` 取 `.first` 会拿到二级，
   老代码里「取 `.last`」的兜底在这里会选错，靠 label_index 精确到最内层那个更稳。
