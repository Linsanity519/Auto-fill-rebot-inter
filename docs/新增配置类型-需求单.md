# 提需求的标准格式

**这份文件解决的问题：** 做一个新功能，一半以上的时间和对话轮次花在
「来回问页面长什么样、这个值从哪儿来、算成功的标准是什么」上。
这些信息你手上本来就有，一次给全，就不用来回问。

> 用法：照下面对应的模板复制一份，填完直接贴给我。
> **填不出来的项写「不知道」**，不要留空 —— 留空我分不清是"没有"还是"忘了写"，
> 只能再问一轮；写「不知道」我就直接去页面上抓。

---

## 第 0 步：先认一下这是哪类需求

| 你想要的 | 类型 | 看哪张单 | 典型成本 |
|---|---|---|---|
| 界面上多一个配置类型（一个新后台 / 新表单从零接进来） | **A. 新配置类型** | [模板 A](#模板-a新配置类型) | 大 |
| 已有的配置类型上多填几个字段 / 多一个选项 | **B. 加字段** | [模板 B](#模板-b在已有配置类型上加字段) | 小 |
| 某个字段填不对、报错、卡住、填了没生效 | **C. 修 bug** | [模板 C](#模板-c填不对修-bug) | 中 |
| 太慢 / 想更自动 / 界面不好用 | **D. 改体验** | [模板 D](#模板-d慢或不好用) | 中 |

分不清就按 A 填，多填的部分不会浪费。

## 模板 A：新配置类型

```
【要做什么】
一句话：___________（例：把「XX后台的YY单元」接进来，按 Excel 批量建）

【页面】
系统名称 / 网址：___________
需要几步走完一条：□ 一个弹窗填完提交  □ 整页表单 + 跳转  □ 活动→单元→创意 多层
登录方式：□ 和现有的一样（内网扫码）  □ 别的：______

【一条数据是什么】
一行 Excel = 一个什么：___________（一个单元？一条创意？一个人群？）
一次大概跑多少条：______

【字段：这是最关键的一段】
把页面上要填的字段列出来，每个给这四样：

| 字段名（页面上的原文） | 控件类型 | 值从哪来 | 备注 |
|---|---|---|---|
| 例：单元名称 | 输入框 | Excel 每行不同 | |
| 例：生效平台 | 多选框组 | 全批一样，配一次 | 默认全选，要取消不该勾的 |
| 例：人群包 | 可搜索下拉 | 全批一样，但要按单元名分几套 | 选项 200+ 个 |

控件类型只要写你在页面上看到的样子就行：
  输入框 / 下拉 / 可搜索下拉 / 多选下拉 / 单选 / 勾选框组 / 日期 / 日期区间 /
  上传图片 / 卡片点选 / 拖拽排序 / 不知道

「值从哪来」只有三种，务必分清（**这决定了 Excel 出哪些列，填错要返工**）：
  ① Excel 每行不同     → 出模板列
  ② 全批一样，配一次   → 进「准备」页或策略中心，不出模板列
  ③ 按某个条件分几套   → 进策略中心的方案组

【联动】（想不起来就写"不知道"，我去页面上试）
选了 ___ 之后才会出现 ___
选了 ___ 之后 ___ 会消失 / 变成另一套字段
填 ___ 之前必须先填 ___

【怎么算成功】
提交之后页面上出现什么？：□ URL 跳转  □ 弹窗消失  □ 绿色提示条  □ 别的：______
提交失败时错误显示在哪：___________

【要不要停下来给人看】
□ 每条都停（默认）  □ 只在第一条停  □ 不停

【能不能给我这些】（有一样算一样，每一样都能省一大截）
□ **浏览器开着、登录好，网址给我** —— 有这个我就能自己跑抓取器，
  上面「字段」那一大段你可以整段留白，我 dump 完再拿给你确认
□ 一条已经配好的、正确的样例（给个 ID / 链接，我直接照着抓）
□ 后端接口（有的话最省事，一个接口顶几百行选项抓取）
□ 一份填好的 Excel（哪怕只有两行）
□ 页面截图（字段那一屏 + 联动展开后那一屏）
```

> **最省事的一种提法**：把「要做什么 / 页面网址 / 一条数据是什么 / 怎么算成功」
> 四段填了，浏览器登录好，剩下的交给我 ——
> 字段全表和联动我用 `tools/capture.py` 自己 dump（见 `docs/README.md`「怎么抓」），
> dump 完拿给你确认「这几个值是每行都不一样，还是全批一样」。
> **这一句判断只有你能给，抓取器抓不出来，它决定 Excel 出哪些列。**

### 填好长什么样（真实例子：价格面板配置「生效渠道=定向」）

> 【要做什么】价格面板配置支持定向投放
> 【页面】manager.bilibili.co 老后台，单元编辑页
> 【字段】「生效渠道」下拉，值：全局 / 定向，全批一样、配一次
> 【联动】**选「定向」之后，人群 / 生效平台 / 运营商 / 省份 / 投放区域 / 频次 /
> 优先级 / 内容设置 / 赠单片 / 创意赛马 全部消失，多出一个「价格面板panel_type」**
> 【样例】运营手工配好的单元 40521，照它抓
> 【坑（你知道的话）】定向下每个选中的套餐都要填 pid，搭售是"无"的也要，
> 少一个页面就不让保存、还不给提示

**这条「联动」和这条「样例」，一句话省掉了大约半天的试错。**
它决定了 Excel 出哪些列 —— 而 Excel 列是在跑之前就定死的，发现晚了整个模板要重做。

## 模板 B：在已有配置类型上加字段

```
【哪个配置类型】___________
【加什么字段】页面原文名：___________
【控件类型】___________
【值从哪来】□ Excel 每行不同  □ 全批一样  □ 按单元名分几套
【必填吗】□ 必填  □ 选填
【有联动吗】选了 ___ 才出现 / 出现之后 ___ 会变
【选项全集】（下拉/单选类必给，或者告诉我"去页面上抓"）
【一条正确样例】ID 或链接：___________
```

这类改动**通常只动 `config/forms/<配置类型>.yaml` 一个文件**，不用改 Python。
如果控件类型是现有 filler 没见过的，才需要加代码 —— 我会明确告诉你是哪种情况。

## 模板 C：填不对 / 修 bug

```
【哪个配置类型 + 哪个字段】___________
【期望】应该填成什么：___________
【实际】实际变成了什么：___________
【报错原文】（有就整段贴，截图也行）___________
【复现】□ 每次都这样  □ 偶尔  □ 只有某几条这样：______
【出错那条的数据】Excel 那一行 / 单元名 / ID：___________
【截图】output\screenshots\ 下对应那张（失败时会自动存）
【日志】run.log 最后 50 行
```

⚠ **截图 + 报错原文这两样，有和没有的差别是 3 轮对话 vs 1 轮。**
这个项目每条失败都会自动截图存在 `output\screenshots\`，直接把那张给我。

## 模板 D：慢 / 不好用

```
【哪一步慢】___________
【多慢】每条大约 ___ 秒，一批 ___ 条，总共 ___ 分钟
【你希望】___________
【跑的时候那个 Chrome 窗口在前台吗】□ 在  □ 不在  □ 没注意
```

⚠ 最后那一项不是废话：Chrome 会把后台标签页降频，**同一段代码慢 15 倍**。
历史上「填创意 12 秒/条」的根因就是这个（见 commit `29aefa3`）。

## 不管哪类，都别做的两件事

1. **不要只给截图就说「照这个配」。** 截图上看不出控件的真实类型
   （多选下拉和勾选框组长得几乎一样，填法完全不同），也看不出联动。
   截图是好东西，但要配一句「这个字段是下拉/勾选」。
2. **不要转述运营给的口径表当字段名。** 页面上写的是「我想投放」，
   口径表上写的是「人群标签」—— 这件事已经翻车过一次，见 `docs/README.md` 的「教训」。
   口径表用来对齐**业务含义**，字段名和选项一律以页面为准。
