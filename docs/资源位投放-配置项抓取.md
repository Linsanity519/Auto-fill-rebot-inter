# 资源位投放 — 现有配置项全量抓取

抓取来源：`rich-vip.bilibili.co` 大会员投放系统（prod），2026-08-07。
入口：投放管理 → 大会员投放系统 → 投放 → 活动 / 单元 / 创意（三级漏斗）。

投放对象模型是三层：**活动（Activity） → 单元（Unit） → 创意（Creative）**。
「新建活动」保存并下一步后进入单元；单元必须挂在一个已有活动下（点「新建单元」会先弹「选择活动」）。

## 二、单元层（Unit）

页面（新建态）：`/delivery/unit/0?state=create&activityId=<id>&activityName=<name>&activityState=0&activityType=<n>`
页面（编辑态）：`/delivery/unit/<unitId>?state=edit&...&position=<positionId>`

> ⚠️ **编辑态下「投放展示位置」是锁死的**，只有新建态能选资源位。

页面分区：**基本信息 → 定向投放 → 投放设置 → 其他设置 → 算法策略 →（操作日志）**
底部操作：`保存并下一步` / `保存返回` / `取消`

  - tab 只做锚点滚动，表格始终是全量 64 条

- **人群选组**：基本人群（实时数据）
- **在上述投放中我想排除**：如「在期大会员」
- 子条件：`在期大会员即期 [X] 天 至 [Y] 天（从小到大）`
- `添加排除人群配置`
