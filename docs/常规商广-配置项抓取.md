# 常规商广投放 — 配置项抓取

> ⚠ **草稿 / 部分实抓。** 2026-09-03 挂在用户已登录的调试 Chrome 上，
> 对 `ad.bilibili.co/#/promote/auto?type=1`（账户当前登录的那个）逐项点开抓的。
> 计划层 + 单元层的字段和选项是实抓；**转化目标的联动矩阵只抓了「交易经营」一行**，
> 其余三个推广目的用到时再补。创意层的「6 个文案」入口只定位到 `.batch-title-drawer`，
> 具体填法要拿到用户给的文案后实跑一遍确认。

## 一句话

和「原生商广」是**同一个系统、同一个页面组件**（iView、`class` 前缀 `ivu-`，
计划/单元/创意一页、底部一个「保存」）。区别只在：原生把 推广目的 / 推广内容 /
转化目标 写死，常规商广要**让用户选**，且创意走「我的视频」而不是按 avid 搜。

- form_url: `https://ad.bilibili.co/#/promote/auto?type=1`
- 框架：iView（`ivu-form-item` / `ivu-select` / `ivu-radio-wrapper`），
  大量选项是 `div.radio-item`，靠 `active` 类判选中 —— 和原生一致，`ad_filler` 那套能复用
- ready_selector：`input[placeholder="请输入单元名称"]`（沿用原生）
- submit_button：`保存`
- **`?campaign_id=<id>` 是否像原生一样"挂到已有计划下只建单元+创意"——待实跑确认**
  （原生是第一个单元 `?type=1` 建计划，之后每个单元 `?campaign_id=`；常规商广大概率一样）

## 创意层：走「我的视频」

「上传创意素材 → 添加稿件/视频」打开抽屉：

- 抽屉：`.ivu-drawer.ivu-drawer-right`
- 顶部子账户切换按钮：**品牌银行 / 三连账户**（截图里选的是「三连账户」）
- 内容 Tab（`a.tab-link`）：bilibili账号稿件 / 花火内容稿件 / 普通内容稿件 / **我的视频**
- 底部按钮：取消 / **下一步批量选封面** / 确定
- 已选计数：`已选 x/10`（一次最多 10）

### 「我的视频」Tab

| 项 | 值 |
|---|---|
| 视频卡片 | `.video-card.rev.video-select-item`（**20 个 / 页**） |
| 勾选控件 | 卡片内 `.video-checkbox`（`ivu-checkbox`，点它，不是点卡片） |
| 标题 | 卡片内 `.vm` / `.video-info` |
| 排序下拉 | `发布时间从近到远`（另一个值：`发布时间从远到近`），**默认「从近到远」** |
| 搜索框 | `请输入视频名称搜索` / `请输入视频bvid或avid搜索` |
| 翻页 | `.ivu-page`，`共 N 条`，20/页 |

> ⚠ **「跳过前 N 个 + 顺延」依赖排序稳定。** 排序默认「发布时间从近到远」，
> 新发的视频会挤到最前面，两次运行之间列表会漂 —— runner 要么把用到的 bvid
> 记进断点、要么每批跑之前让用户确认「前 N 个」还是那几个。

### 加进来之后的创意块

- `.single-creative-wrapper`，`data-id="c_0_<avid>_<随机数>"` —— **和原生同构**，
  `block_avid_attr: data-id` 那套能复用
- 默认「极简创编」模式：只有一个「**立即填充**」按钮（AIGC 自动生成封面/标题/描述）
- 创意名称：输入框，默认 `创意_N`，不用改
- 封面：`.aigc-cover-item`，计数 `1/6`，有「添加封面」；默认用稿件原始封面
- **「6 个文案」入口**：DOM 里有个 `.batch-title-drawer`（`aria-label="批量添加标题"`，
  默认 `display:none`，宽 1000px，底部「取消 / 保存」）。
  **触发按钮没定位到** —— 大概率要先点「立即填充」把标题列表生成出来，
  才会出现「批量添加标题」按钮。拿到用户的 6 条文案后实跑一遍确认：
  是批量粘贴（一行一条）还是逐条加、上限是不是 6、和封面是不是绑定。

## 已定（2026-09-03 用户确认，多轮迭代后的最终版）

- 推广目的 / 推广内容 / 转化目标：准备页**联动下拉**（`options_by` / `options_map`）。
  **只保留 3 组**：交易经营→电商链接、内容种草→内容投放、销售线索收集→线索。全量矩阵留在上面表里备查
- 视频：准备页填「视频数量 N」+「跳过前几个 K」，从「我的视频」跳过前 K 个往下顺延取 N 个。
  **每 10 个视频归一个单元**（页面上限），一个视频一条创意。填 50 = 5 个单元
- 每条创意的 **素材标题 / 素材描述 / 落地页 进 Excel**，一行一个视频、行序对应视频顺序：
  · 素材标题：一格里换行写多条，≤6 条，每条 2~40 字
  · 素材描述：2~10 字
  · 落地页：https 链接（走「自定义链接」）
- **空间设置** = 第一个「稿件UP主空间」，**Story 转化组件** = 弹层里第一个（默认）
- 定向：和原生一致（`编辑定向` → 人群包 = 不限/指定人群包/排除人群包 → 确认）
- 单元名：`常规商广_{日期}_{序号}`
