C

换技术栈

信息架构同 B —— C 是换实现，不是换布局。差别在于 Qt / 内嵌网页免费给到的东西：深色模式、真圆角与投影、分段控件、过渡动画、气泡提示。下面这张按深色渲染，因为那是最直观的一项。

界面代码本身不比 B 慢——Qt 的表格、堆叠页、样式表比 tkinter 省事，自绘圆角按钮和队列泵都可以删掉。 多出来的 2–3 天几乎全在打包：PyInstaller 收 Qt 插件目录、体积、以及在没装 Python 的同事机器上验证跑得起来。
